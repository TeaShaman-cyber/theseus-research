# Theseus 1.0 Active Research Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a truthful Theseus 1.0 public-program baseline that describes the already-active research program without promoting unfinished research or the pending registry into authority.

**Architecture:** One bounded release PR updates the bilingual root contract and its changelog atomically, adds a small durable research navigation index, and synchronizes only the methodology contract-version metadata. Live work remains in GitHub Issues/PRs; the pending machine-readable registry is not required for 1.0.

**Tech Stack:** Markdown, Git, GitHub review/readback.

**Spec:** `docs/research/2026-09-06-theseus-1.0-migration-map.md`

## Global Constraints

- Preserve all existing contract invariants: consent, provenance, reversibility, sponsor independence, public-interest/non-commercial status, and explicit human acceptance.
- `1.0` means ACTIVE RESEARCH baseline, not completed research.
- External review remains welcome but is not a gate for ordinary research work.
- Compatible support must not buy authority over findings, publication, consent/safety boundaries, or ethical purpose.
- `registry/research-lines.json` is not part of the accepted baseline unless its independent track has merged.
- Research merge, methodology promotion, registry membership, and contract acceptance remain distinct operations.
- English and Russian contract meaning must remain synchronized in the same revision.
